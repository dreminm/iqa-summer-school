01

Problem

Most NR-IQA models infer quality directly from image features. This project tests whether a separate, image-specific distortion representation d(x) makes the quality head more accurate on unseen distortion families.

Research question With the image encoder, prior encoder, training data, loss, and parameter budget fixed, which way of injecting d(x) gives the best out-of-distribution quality prediction?

Compare

  • No distortion prior
  • Additive query conditioning
  • FiLM query conditioning
  • Prefix key/value token

Keep fixed

  • Frozen CLIP image encoder
  • Frozen ARNIQA prior encoder
  • Head width and trainable budget
  • Data splits, loss, and optimizer

Blind setting: the model may use only the image at inference time. Ground-truth distortion labels are not model inputs.

C3

Prefix K/V

Append projected d to the image tokens as one key/value token.

Distortion prior: use the normalized embedding from the frozen ARNIQA encoder, before its quality regressor. Project it to the query dimension with one trainable linear layer.

03

First steps

  1. Step 1

    Read three papers

    MP-IQEQuery-based aggregation and multimodal prompts. Use it for architecture context, not as the baseline implementation. ARNIQAWhy its frozen representation is a reasonable distortion prior. LIQEJoint quality, scene, and distortion modelling with vision-language features.
  2. Step 2

    Download the datasets

    KADID-10kTrain, validation, in-domain test, and distortion-family holdout.Official download
    CSIQExternal synthetic-distortion test only.Author page
    TID2013External taxonomy transfer test only.Official download
  3. Step 3

    Create the starter repository

    Use one shared pipeline for all variants. The repository should contain the baseline, experiment configs, evaluation code, and a minimal scoring service.

    src/iqa/data/            # manifests, splits, score normalization
src/iqa/encoders/        # CLIP and ARNIQA wrappers
src/iqa/heads/           # baseline and conditioning modules
src/iqa/evaluation/      # SRCC, PLCC, bootstrap, latency
configs/                 # one file per experiment
scripts/train.py
scripts/evaluate.py
service/app.py            # POST /score
tests/
  4. Step 4

    Make the baseline trustworthy

    • Build one manifest: path, score, reference_id, distortion_id, severity.
    • Split by reference_id, never by individual distorted images.
    • Pass one forward/backward batch.
    • Overfit 64 images before the first full run.
    • Freeze CLIP with eval() and requires_grad=False.
  5. Step 5

    Run the controlled experiment

    Train B0 and C1–C3 with the same configuration. Then run seven distortion-family holdouts on KADID-10k and final zero-shot tests on CSIQ and TID2013. For C1–C3, evaluate the same trained checkpoint with matched, shuffled, and zeroed priors.

04

Expected result

The project is complete when the team can answer whether the prior helps, which injection mechanism is best, and whether the gain survives unseen distortions.

01

Reproducible code

Versioned manifests and splits, locked dependencies, configs for B0/C1/C2/C3, tests, and one command for the best model.

02

Comparison table

Mean ± standard deviation over three seeds for KADID, seven family holdouts, CSIQ, and TID2013.

03

Prior intervention

Matched vs. shuffled vs. zeroed d(x) for every conditioning variant.

04

Deployable scorer

A minimal POST /score endpoint that returns the scalar score and inference time for the selected model.

Primary decision rule

Rank models by mean distortion-family-holdout SRCC. Use external-dataset SRCC, trainable parameters, and batch-1 latency as secondary criteria. A clear negative result is valid if the protocol is reproducible.
