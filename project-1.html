Instruction-Conditioned Quality Embeddings

01

Problem

Standard NR-IQA models produce one fixed representation and one overall quality score. This project studies whether quality features can instead be extracted according to a natural-language instruction such as assess sharpness, estimate visible noise, or judge overall perceptual quality.

Research question Can instruction-conditioned queries turn the same CLIP tokens into criterion-specific quality embeddings, and does an image-specific ARNIQA prior make this readout more accurate and robust?

Instruction

Defines what to evaluate: overall quality, sharpness, noise, contrast, colorfulness, or exposure. Its embedding changes the query used to read the image.

ARNIQA prior

Describes how the image is degraded. Its frozen distortion-manifold embedding supplies image-specific perceptual information that text alone cannot provide.

Central hypothesis: language should control feature extraction, not merely be concatenated after visual pooling. ARNIQA is a complementary perceptual prior, not a replacement for the instruction.

  4. Step 4

    Establish the baselines

    • Reproduce one specialist model per criterion.
    • Train the shared task-ID and late-instruction baselines.
    • Use multiple instruction paraphrases and reserve unseen phrasings for evaluation.
    • Verify that different criteria produce different targets for the same image.
  5. Step 5

    Test conditioning and transfer

    Train M1 before adding ARNIQA in M2. Evaluate per-criterion accuracy, KonIQ↔SPAQ transfer, unseen instruction paraphrases, and matched, wrong, shuffled, or zeroed conditions. Inspect whether instructions change query attention over the same image.

04

Expected result

The project should produce one compact encoder that returns a quality embedding and score for a requested perceptual criterion, while making the contribution of language and the ARNIQA prior measurable.

01

Quality encoder

A trained instruction-conditioned query adapter over frozen CLIP features, with an optional ARNIQA prior.

02

Controlled benchmark

Specialists, task IDs, late fusion, instruction queries, and instruction + ARNIQA under one protocol.

03

Behavior evidence

Paraphrase consistency, wrong-instruction and shuffled-prior interventions, plus criterion-dependent attention maps.

04

Reusable artifacts

Code, configurations, prompt bank, checkpoints, and a simple API for criterion-conditioned scoring.

Success criterion

Full natural-language instructions must outperform a discrete task ID, query conditioning must outperform late fusion, and ARNIQA must add a reproducible gain beyond instruction-only queries. The best model should retain that gain on cross-dataset transfer and unseen paraphrases.
